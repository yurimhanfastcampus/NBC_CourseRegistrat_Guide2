# 내일배움카드 수강신청 가이드

패스트캠퍼스 국비지원 '매일배움' 과정 수강생을 위한
**"자부담비 결제 → 고용24 수강신청"** 안내 가이드 페이지입니다.

[처음부터 시작하기] 버튼으로 1단계(자부담비 결제) → 2단계(고용24 수강신청) 순서로 순차 진행하며,
두 단계를 모두 완료해야 최종 훈련생으로 등록되는 절차를 스크린샷과 함께 안내합니다.

## 페이지 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 메인 — [처음부터 시작하기], 전체 절차 요약, 자주 묻는 질문(통합) |
| `payment.html` | 1단계. 자부담비 결제 (커널 아카데미) |
| `employ24.html` | 2단계. 고용24 수강신청 + 완료 안내 |
| `guide.html` | 수강 안내 — 절차, 수료 조건, 수강 방법 |

※ 파일명은 기존 배포 링크 유지를 위해 그대로 두고, 내용과 메뉴 라벨만 1단계/2단계로 변경했습니다.

## 폴더 구조

```
├── index.html
├── payment.html
├── employ24.html
├── guide.html
├── assets/
│   ├── style.css
│   └── script.js
└── images/        # 단계별 안내 스크린샷
```

## 로컬에서 확인하기

`index.html`을 브라우저로 바로 열거나, 로컬 서버로 실행합니다.

```bash
python -m http.server 8080
# 또는
npx serve .
```

이후 `http://localhost:8080` 접속

## 주요 기능

- 4개 페이지 간 스텝 네비게이션 (현재 페이지 자동 하이라이트)
- 분류별 토글형 FAQ 아코디언 (가장 많이 묻는 질문 / 자부담금 / 신청·자격 / 수강 관련)
- 안내 스크린샷 클릭 시 확대(라이트박스) 보기
- 모바일 대응 반응형 레이아웃
